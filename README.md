EJERCICIO CORTO:

Filtrado y Ordenamiento de Usuarios en Python

Este proyecto contiene un ejercicio práctico en Python para filtrar y 
ordenar una lista de usuarios según criterios específicos.

📌 Descripción del ejercicio

Se debe desarrollar una función que reciba una lista de usuarios con atributos como nombre, 
edad, rol, profesión y sueldo, y que retorne solo los usuarios mayores de edad con rol de 
Empleado o Estudiante, ordenados por edad ascendente y, en caso de empate, por sueldo descendente.

🎯 Objetivo

Este ejercicio refuerza conceptos de manejo de diccionarios, listas, filtrado con condiciones 
y ordenamiento con sorted() y funciones lambda.
